保護靈氣 Pomander

系列說明

作用區域：緊貼肉體的電磁場與乙太體（約身體外圍 2–3 公分）。

主要功能：淨化、修補、保護能量場，像一件「能量外套」，阻絕外界的負面頻率與干擾，維持內在能量的完整與平衡。

成分：49 種草本植物精華、結晶礦物能量與特定色彩頻率，以酒精為基底。

使用方法

  1. 滴 3 滴於左手掌心，雙手合掌微微搓揉，啟動植物與色彩頻率。
  2. 雙手高舉至頭頂上方，將能量掃入身體周圍的氣場（前、後、左、右）。
  3. 從頭頂順著身體一路向下揮動，經由眉心、喉嚨、胸口、腹部，直到腳底。
  4. 在胸口（心輪）前停佇片刻，感受能量護持。
  5. 最後將雙手合十放在口鼻前，做 3 次深呼吸，將氣味吸入體內。
